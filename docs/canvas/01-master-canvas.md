# MASTER CANVAS PROMPT — KAUVEX UNIVERSAL DESIGN STUDIO & POD UPDATE

> Canvas Document 1 — The constitution for the Design Studio update.

## PROJECT CONTEXT

You are **not creating a new platform**.

You are working on an **existing production platform** called **Kauvex**.

Your responsibility is to **extend the existing application** without breaking current functionality.

Current platform:

* Marketplace
* Ecommerce
* Vendors
* Services
* Admin Dashboard
* Customer Dashboard
* Authentication
* AI
* Payments

All existing functionality must continue to work.

This update introduces one of the biggest modules ever added to Kauvex.

---

## PRIMARY OBJECTIVE

Build a **Universal Design & Manufacturing Ecosystem** that works inside Kauvex.

The goal is **NOT** to copy Canva, Adobe, Tailornova, CLO, Rhino, Printful or Printify.

The goal is to create something inspired by the best ideas from each platform while providing a unified experience across industries.

Every industry should share the same core Design Engine while exposing industry-specific tools, workflows, simulations, and manufacturing capabilities.

---

## DESIGN PHILOSOPHY

Kauvex should become:

> Design Everything.

## DEVELOPMENT APPROACH

Before implementing anything:

1. Audit the existing Kauvex codebase.
2. Identify reusable components.
3. Preserve all current features.
4. Design the module architecture.
5. Present the proposed architecture.
6. Then implement incrementally.
7. Test every feature before moving to the next.
